## MODIFIED Requirements

### Requirement: 使用高对比度调色板
系统 SHALL 使用高饱和度、高对比度的颜色方案，使图表线条更显眼。

#### Scenario: 默认调色板
- **WHEN** 用户添加变量到图表
- **THEN** 系统使用高对比度调色板：`['#3b82f6', '#22c55e', '#f59e0b', '#ef4444', '#a855f7', '#06b6d4', '#f97316', '#8b5cf6', '#ec4899', '#14b8a6']`

#### Scenario: 颜色循环
- **WHEN** 添加的变量数量超过调色板颜色数量
- **THEN** 系统从调色板开头循环使用颜色

#### Scenario: 一致性
- **WHEN** 图表面板和图表管理器分配颜色
- **THEN** 两者使用相同的调色板，确保颜色一致性

#### Scenario: 向后兼容
- **WHEN** 用户已有图表变量
- **THEN** 现有变量保持原有颜色，新变量使用新调色板
