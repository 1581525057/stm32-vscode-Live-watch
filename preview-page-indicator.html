设计原则
• 色彩：使用 VS Code 内置 editor.selectionBackground (#264f78) 作为高亮背景
• 指示条：左侧 3px 蓝色边框，对应 activityBarBadge.background
• 圆点：页面圆点指示器，活跃页加蓝色发光，直观显示多页位置
• 图标：使用 VS Code 内置 folder 图标 + charts.foreground 着色
• 简洁：移除 ━━━ Unicode 装饰，用原生 UI 元素替代
