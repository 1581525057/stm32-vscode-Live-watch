实现说明

「···」更多菜单的实现方式：VS Code 原生不支持 view/title 下拉菜单，但可以通过注册一个命令 + vscode.window.showQuickPick() 来模拟。点击「···」按钮时弹出 Quick Pick 菜单，列出所有收纳的操作项。

页面指示器：方案 B/C 中的页面指示器使用 enablement: "false" 的静态命令来显示文本，与当前实现一致。

启动/停止合并：可以合并为一个按钮，根据服务器状态动态切换图标和命令（使用 when 条件）。

标题颜色：VS Code 原生 view 标题不支持内联样式，但可以通过 window.createTreeView() 的 name 属性配合 Unicode 装饰字符来增强视觉效果，或者在树的第一项添加一个装饰性的 header item。
