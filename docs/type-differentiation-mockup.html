变量类型「分辨度」增强方案

让结构体、类、数组在树视图中一目了然

方案 1
语义化图标 + 内置配色
利用 VS Code ThemeIcon 的内置语义色，不同类型使用不同图标名称。零额外代码，纯原生风格。
▼ ⬡ sensor_data { ... } SensorData_t
○temperature = 25.6float
○humidity = 60uint16_t
▼ ⧫ buffer [ ... ] uint8_t[64]
○[0] = 0xFFuint8_t
○[1] = 0x3Auint8_t
▼ ◈ motor_ctrl { ... } MotorController
○speed = 1500int32_t
▼ ◇ data_reg { ... } DataReg_u
○raw = 0xABCDuint32_t
方案 2
类型 Badge 标签
在变量名后面加一个彩色小标签，显示 struct / array / class。最直观，但占用额外水平空间。
▼ ⬡ sensor_data { ... } struct SensorData_t
○temperature = 25.6float
○humidity = 60uint16_t
▼ ⧫ buffer [ ... ] array uint8_t[64]
○[0] = 0xFFuint8_t
○[1] = 0x3Auint8_t
▼ ◈ motor_ctrl { ... } class MotorController
○speed = 1500int32_t
▼ ◇ data_reg { ... } union DataReg_u
○raw = 0xABCDuint32_t
方案 3
符号前缀 + 配色
用独特的符号前缀替代图标：{ } 结构体、[ ] 数组、<> 类、# 联合体。紧凑且辨识度高。
▼ { sensor_data SensorData_t
·temperature = 25.6float
·humidity = 60uint16_t
▼ [ buffer uint8_t[64]
·[0] = 0xFFuint8_t
·[1] = 0x3Auint8_t
▼ < motor_ctrl MotorController
·speed = 1500int32_t
▼ # data_reg DataReg_u
·raw = 0xABCDuint32_t
方案 4
图标 + 容器符号增强
保留语义图标，同时用彩色的容器符号 { } [ ] <> 替代原来的 { ... } [ ... ]。兼顾美观与信息量。
▼ ⬡ sensor_data { ··· } SensorData_t
○temperature = 25.6float
○humidity = 60uint16_t
▼ ⧫ buffer [ ··· ] uint8_t[64]
○[0] = 0xFFuint8_t
○[1] = 0x3Auint8_t
▼ ◈ motor_ctrl { ··· } MotorController
○speed = 1500int32_t
▼ ◇ data_reg { ··· } DataReg_u
○raw = 0xABCDuint32_t

推荐：方案 1 + 方案 4 组合

最佳实践

图标层：用 VS Code ThemeIcon 内置语义色区分类型（struct 青色、class 黄色、array 紫色、union 蓝色），零额外渲染开销。

标签层：容器符号 { } [ ] 用对应类型色着色，替代原来的灰色 { ... } [ ... ]，让颜色从图标延伸到文字，形成视觉连续性。

实现方式：在 VariableTreeItem.buildLabel() 中根据 variableInfo.type 选择着色的容器符号；在构造函数中根据 type 选择对应 ThemeIcon。

代码改动：仅修改 src/variableTreeDataProvider.ts 的 VariableTreeItem 类，约 20 行改动。
